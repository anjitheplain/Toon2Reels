# Privacy

Toon2Reels runs on the device. It has no account, internet permission, server, ads, analytics SDK, or hidden telemetry. The app does not transmit the selected comic, music, crops, or video to Anji or N.

The Android system file picker grants access only to user-selected image/audio URIs. The app can retain a read grant while the project is open, and caches decoded images or temporary renders within app storage. A completed video or cropped PNG is written to the device gallery only when the user taps a save button. An Android share sheet hands the chosen video to an app the user selects; that destination app has its own privacy policy.

The editing project is held in memory and is lost if the process is terminated. Android can remove app-private files on uninstall; gallery files may remain until the user deletes them. No usage measurement is performed. Public GitHub release/download/star/fork statistics are platform-level signals, not an app telemetry channel.
