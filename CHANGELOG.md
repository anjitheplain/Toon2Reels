# Changelog

All notable changes use Semantic Versioning. Git tags have the form `vX.Y.Z`.

## 1.0.0 — prepared for first public release

- Import a bordered comic sheet or multiple panel images, reorder and adjust crops.
- Save current crops as separate PNGs; set individual or all-panel durations.
- Preview and export 1080×1920 H.264 MP4 with optional AAC music, backgrounds, transitions, and Korean title.
- Save to the gallery or share; cancel and retry export.
- Remove the natural motion feature.
- Map extracted sync samples to MediaCodec keyframe flags during MP4 muxing, and explicitly exclude app-private files from Android 12+ backup/transfer.
- Add open source license, attribution, citation, privacy/security policy, agent instructions, metadata, and CI.

Release date and tag will be added when the first GitHub Release is published.
