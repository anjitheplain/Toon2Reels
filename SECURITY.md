# Security policy

## Supported version

The latest published `1.x` release will receive security fixes when a maintainer can reproduce them. Older versions are not guaranteed support.

## Private reporting

After the repository is published, use its GitHub **Security → Report a vulnerability** form. The repository owner must enable private vulnerability reporting in Settings before public launch. Please do not post exploit details or private comic/audio files in public Issues. Until the private route is enabled, contact the project owner privately through a channel they explicitly provide; no unverified email address is listed here.

Include the app version, Android version, reproduction steps, and impact. The owner will triage and coordinate a fix; no response deadline is promised.
